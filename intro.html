Stages 1–2

Narrow models, then the Transformer

STAGE 1 · PRE-2017

Classical machine learning

  • Decision trees, random forests, SVMs, logistic regression
  • Show it 50,000 cats vs. dogs, or 100,000 spam vs. not-spam, and it learns to classify
  • Limit: completely rigid. A spam filter can’t write a sentence.

STAGE 2 · 2017–2022

Transformers and LLMs

  • Google’s 2017 paper “Attention Is All You Need”
  • Self-attention: every token weighs every other token, near or far
  • Trained only to predict the next token, models picked up grammar and world knowledge
  • Foundation models: GPT-3, PaLM, LLaMA

Stage 3 · 2022–2024

Chatbots and the single-turn trap

A chatbot can tell you how to fix a locked Active Directory account.

It can’t fix it.

Frozen in a vacuum

It answers from its context window and stops. No hands, no clock, no way to check its answer.

RLHF made it helpful

Human feedback turned raw text predictors into assistants: ChatGPT, Claude, Gemini.

But still passive

Great for “Explain NTFS permissions.” For real work, you copy, paste and run.

Stage 4 · 2024–now

Agents: the ReAct loop

1

Reason

Plan what needs to happen

2

Act

Emit a structured tool call

3

Observe

Read the real output or error

4

Iterate

Fix, retry, continue until done

reason › I need to see which volumes are low on space.

act › run_command("Get-Volume")

observe› stdout / stderr returned into the model’s context

iterate› diagnose, pick the next command, repeat until the goal is met

Now it talks to tools and corrects itself — not just to you.

The lexicon · 3 of 3

The system around the model

Harness

Software around the model that manages system prompts, history, token budgets, the tool loop and safety guards.

The chassis, steering, brakes and dashboard around the engine.

Agent

An LLM paired with tools, memory and an autonomous loop, pursuing a goal over many steps.

A rover that reads telemetry, decides, navigates and reports back.

MCP

An open JSON-RPC spec for how harnesses read data (Resources), run actions (Tools) and load templates (Prompts).

A universal USB-C hub for Windows, Linux, databases and switches.

Live demo 2 · Admin automation

An agent audits a Windows box

PROMPT

I need a robust PowerShell script to audit our local Windows storage and user accounts. It must:

1. List all local users with their Enabled status, LastLogon date, and PasswordNeverExpires flag.

2. Query all attached disks, partition styles (GPT vs MBR), free space percentage, and health status.

3. Check for any VHD/VHDX virtual disk files mounted under Hyper-V or disk management.

4. Export the findings to both a clean console table and a structured JSON report in C:\Audit.

Make it safe: run with -WhatIf support and include try/catch error handling.

POINT OUT IN THE OUTPUT

Security and governance

Trust, but verify

Keep secrets out of prompts

Never paste API tokens, private SSH keys or Kerberos tickets into a public AI tool. Scan for secrets and PII before you commit.

Read before you run

rm -rf, Format-Volume, Remove-Item -Recurse: a human approves every destructive command an agent proposes.

Know where your data goes

Consumer accounts may use your chats to train models. Enterprise and API agreements can offer zero data retention.

AI isn’t only in the cloud

Local open weights vs. cloud frontier

Cloud frontier APIs

  • Strongest reasoning, biggest context windows
  • Nothing to host or maintain
  • Prompts and data leave your network
  • Check the provider’s retention terms

Local open weights

  • Ollama or vLLM on a Proxmox server or workstation GPU
  • Zero telemetry, complete data sovereignty
  • Works offline and air-gapped, with predictable performance
  • Smaller models: less capable on the hardest tasks

Who runs local? Banks, healthcare and air-gapped defense networks.
